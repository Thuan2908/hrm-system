# System Overview

## Actors
- Admin
- Manager/Leader
- HR Manager
- Employee
- Bank Integration

## Core flow
1. HR onboarding employee.
2. Account + role được tạo.
3. Employee check-in/out và gửi đơn online.
4. Leader và HR duyệt.
5. Cuối kỳ, HR chốt công.
6. Payroll đọc dữ liệu employee + attendance + allowance/deduction.
7. Payslip được phát hành.
8. Bank export file được tạo.
9. Dashboard/report đọc dữ liệu tổng hợp.
