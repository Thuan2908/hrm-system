# ADR-010-payroll-finalization: Immutable Finalized Payroll

Status: Accepted

## Context
Payroll là dữ liệu tài chính cần truy vết.

## Decision
Sau finalize chỉ điều chỉnh bằng adjustment/audit.

## Consequences
- Tăng tính nhất quán và khả năng audit.
- Mọi thay đổi trái quyết định này phải có ADR thay thế.
