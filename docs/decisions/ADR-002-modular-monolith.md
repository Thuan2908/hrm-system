# ADR-002-modular-monolith: Use Modular Monolith

Status: Accepted

## Context
HRM có nhiều domain nhưng quy mô dự án chưa cần microservices.

## Decision
Dùng modular monolith với boundary rõ.

## Consequences
- Tăng tính nhất quán và khả năng audit.
- Mọi thay đổi trái quyết định này phải có ADR thay thế.
