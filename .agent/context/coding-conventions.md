# Coding Conventions

- Code, class, field, API path: English.
- Product docs: Vietnamese.
- File names: kebab-case.
- Type/class/interface: PascalCase.
- function/variable: camelCase.
- Constants: UPPER_SNAKE_CASE.
- API DTO suffix: `Dto`.
- Repository implementation suffix: `Repository`.
- Domain error code theo mẫu `MODULE_REASON`, ví dụ `EMPLOYEE_NOT_FOUND`.
- Không dùng magic number cho payroll hoặc permission.
