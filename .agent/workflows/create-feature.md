# Workflow: Create Feature
1. Đọc PRD/business rule liên quan.
2. Xác định module và boundary.
3. Xác định entity/DTO/API bị ảnh hưởng.
4. Kiểm tra ADR.
5. Viết/ cập nhật task acceptance criteria.
6. Thiết kế DB change nếu có.
7. Implement BE.
8. Viết test BE.
9. Implement FE.
10. Viết test FE/E2E phù hợp.
11. Kiểm tra permission/audit.
12. Cập nhật docs và task status.
