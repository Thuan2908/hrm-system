# Task Lifecycle

## BACKLOG
Ý tưởng/yêu cầu chưa đủ thông tin.

## READY
Requirement và Acceptance Criteria rõ, dependency đã xác định.

## IN_PROGRESS
Đang triển khai.

## REVIEW
Code review + architecture review.

## QA
Test tích hợp/regression.

## UAT
Business user xác nhận.

## DONE
Đã merge/deploy theo milestone và docs được cập nhật.
