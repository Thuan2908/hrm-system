# Definition of Done
- Code đạt acceptance criteria.
- Test pass.
- Authorization đúng.
- Audit đúng nếu cần.
- Schema change có migration SQL/hướng dẫn áp dụng thủ công và rollback/forward plan (ADR-016); không có initializer/seed script tự động.
- Docs cập nhật.
- Không còn TODO blocker.
- QA/UAT đạt yêu cầu với flow critical.
